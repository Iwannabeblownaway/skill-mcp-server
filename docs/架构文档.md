## 2. 技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| MCP 协议 | mcp Python SDK | Streamable HTTP transport |
| Web 框架 | FastAPI | 提供 REST API 和 MCP endpoint |
| 数据库 | MySQL | 存储用户、技能元数据、授权、日志 |
| 缓存 | Redis | 可选，用于会话缓存 |
| 认证 | API Key | 支持 `X-API-Key` header 和 `?key=` query param |
| ORM | aiomysql | 异步 MySQL 驱动 |
| 内容存储 | 文件系统 | Skill 内容存储在 `skills/{name}/` |

## 3. 混合存储方案

### 3.1 存储策略

采用**混合存储方案**：
- **数据库（MySQL）**：存储技能元数据（name, description, path, version, content_json）
- **文件系统**：存储技能内容（`skills/{name}/` 目录下的文件）

### 3.2 优点

1. **灵活性**：内容可以直接用 Markdown 编辑器编辑
2. **版本控制**：文件系统内容可直接 git 管理
3. **性能**：数据库只存索引，读取内容从文件系统加载
4. **可扩展**：支持大文件或二进制资源

### 3.3 数据流

```
创建技能：
  1. API 接收 name, description
  2. 在数据库插入元数据（path = name）
  3. 创建目录 skills/{name}/
  4. 创建 SKILL.md 模板文件

读取技能：
  1. 查询数据库获取 path
  2. 从 skills/{path}/ 读取内容
  3. 返回给客户端
```

## 4. 核心模块

### 4.1 MCP Handler (`app/mcp/`)

| 文件 | 职责 |
|------|------|
| `server.py` | MCP Server 实例，认证中间件 |
| `handlers.py` | 工具处理（list_tools, call_tool） |
| `session.py` | 会话管理 |
| `auth.py` | MCP 认证 |

#### 认证中间件
```python
# 支持 X-API-Key header 和 ?key= query param
api_key = request.headers.get("X-API-Key") or request.query_params.get("key")
user = await verify_api_key(api_key)
current_user.set(user)  # 设置到上下文
```

#### tools/list 实现
```python
async def handle_list_tools(session_id: str) -> list[Tool]:
    user_id = await get_user_id_from_session(session_id)
    skills = await get_user_skills(user_id)
    # 转换为 MCP Tool 格式返回
```

#### tools/call 实现
```python
async def handle_call_tool(session_id, tool_name, arguments):
    skill_name = tool_name[len("use_skill_") :]
    content, error = await get_skill_content(user_id, skill_name)
    return [TextContent(type="text", text=content or error)]
```

### 4.2 REST API (`app/api/v1/`)

| 文件 | 职责 |
|------|------|
| `users.py` | 用户 CRUD（创建返回 API Key） |
| `skills.py` | 技能 CRUD（自动创建 skill 目录）、文件上传、内容管理 |
| `auth.py` | 授权管理（grant/revoke skill） |
| `logs.py` | 调用日志查询 |

### 4.3 业务逻辑层 (`app/services/`)

| 文件 | 职责 |
|------|------|
| `skill_service.py` | 技能获取、权限检查、日志记录、内容加载、索引/文件读取 |
| `user_service.py` | 用户验证、创建 |

### 4.4 数据访问层 (`app/db/crud/`)

| 文件 | 职责 |
|------|------|
| `user.py` | 用户 CRUD |
| `skill.py` | 技能 CRUD（含文件系统操作） |

## 7. API 认证

所有管理 API 需要 `X-API-Key` Header：
```bash
curl -H "X-API-Key: YOUR_API_KEY" http://localhost:8000/api/v1/users
```

MCP 端点支持两种方式：
```bash
# Header 方式（推荐，更安全）
curl -H "X-API-Key: YOUR_API_KEY" "http://localhost:8000/mcp"

# Query param 方式（兼容旧客户端）
curl "http://localhost:8000/mcp?key=YOUR_API_KEY"
```

## 8. 错误处理

| 场景 | HTTP Status | 错误信息 |
|------|-------------|----------|
| 缺少 API Key | 401 | `Missing API key. Provide via X-API-Key header or ?key= query param` |
| 无效 API Key | 401 | `Invalid API key` |
| 非管理员操作 | 403 | `Admin privileges required` |
| 资源不存在 | 404 | `User/Skill not found` |
| 文件不存在 | 404 | `Skill file not found` |
| 路径穿越检测 | 400 | `Path traversal detected` |
| 参数错误 | 422 | Pydantic validation error |

## 9. 扩展性设计

### 未来可扩展

1. **多租户**: 增加 `tenant_id` 字段，中间件过滤
2. **技能版本**: skills 表支持同一名称多版本，path 包含版本号
3. **缓存**: list_tools 结果缓存到 Redis（TTL 5分钟）
4. **Rate Limiting**: 使用 Redis 实现

## 10. 安全措施

- **路径穿越防护**: 所有文件操作验证 resolve() 后的路径
- **CORS 配置**: 开发环境 localhost 白名单，生产环境需配置具体来源
- **API Key 管理**: 数据库存储，支持随机生成
- **参数化查询**: 所有 SQL 使用参数化查询防止注入
