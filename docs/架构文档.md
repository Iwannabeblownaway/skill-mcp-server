# 架构文档：SKILL 服务端（MCP 协议）

> 版本：v1.0 | 更新日期：2024-04-16

## 1. 总体架构

```
┌─────────────────┐     MCP/HTTP    ┌─────────────────────────────────┐
│  MCP 客户端      │ ◄────────────► │         SKILL 服务端             │
│  (OpenCode)     │                │                                 │
└─────────────────┘                │  ┌─────────────┐  ┌───────────┐  │
                                   │  │ MCP Handler │  │ REST API  │  │
                                   │  │ (contextvar)│  │ /api/v1   │  │
                                   │  └──────┬──────┘  └─────┬─────┘  │
                                   │         │               │        │
                                   │  ┌──────▼───────────────▼────┐   │
                                   │  │      Service Layer       │   │
                                   │  │   skill_service.py       │   │
                                   │  └──────┬───────────────┬────┘   │
                                   │         │               │        │
                                   │  ┌──────▼────┐  ┌──────▼────┐   │
                                   │  │   MySQL   │  │   Redis   │   │
                                   │  │(数据存储) │  │ (会话缓存) │   │
                                   │  └───────────┘  └───────────┘   │
                                   └─────────────────────────────────┘
```

## 2. 技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| MCP 协议 | mcp Python SDK | Streamable HTTP transport |
| Web 框架 | FastAPI | 提供 REST API 和 MCP endpoint |
| 数据库 | MySQL | 存储用户、技能、授权、日志 |
| 缓存 | Redis | 可选，用于会话缓存 |
| 认证 | API Key | query param `?key=` 方式 |
| ORM | aiomysql | 异步 MySQL 驱动 |

## 3. 核心模块

### 3.1 MCP Handler (`app/mcp/server.py`)

#### 认证中间件
```python
# 使用 contextvars 在异步 handlers 间传递用户上下文
current_user: ContextVar[dict | None] = ContextVar("current_user", default=None)

async def auth_middleware(scope, receive, send, next_handler):
    api_key = request.query_params.get("key")
    user = await verify_api_key(api_key)
    current_user.set(user)  # 设置到上下文
```

#### tools/list 实现
```python
@mcp_server.list_tools()
async def list_tools() -> list[MCPTool]:
    user = current_user.get()  # 从上下文获取用户
    user_id = user.get("id")
    # 查询用户授权的 skills
    user_skills = await user_skill_crud.get_user_skills(conn, user_id)
    # 转换为 MCP Tool 格式返回
```

#### tools/call 实现
```python
@mcp_server.call_tool()
async def call_tool(name: str, arguments: dict) -> list[TextContent]:
    user = current_user.get()
    skill_name = arguments.get("skill_name")
    content, error = await get_skill_content(user_id, skill_name)
    return [TextContent(type="text", text=content or error)]
```

### 3.2 REST API (`app/api/v1/`)

| 文件 | 职责 |
|------|------|
| `users.py` | 用户 CRUD（创建返回 API Key） |
| `skills.py` | 技能 CRUD |
| `auth.py` | 授权管理（grant/revoke skill） |

### 3.3 业务逻辑层 (`app/services/`)

| 文件 | 职责 |
|------|------|
| `skill_service.py` | 技能获取、权限检查、日志记录 |
| `user_service.py` | 用户验证、创建 |

### 3.4 数据访问层 (`app/db/crud/`)

| 文件 | 职责 |
|------|------|
| `user.py` | 用户 CRUD |

## 6. API 认证

所有管理 API 需要 `X-API-Key` Header：
```bash
curl -H "X-API-Key: YOUR_API_KEY" http://localhost:8000/api/v1/users
```

MCP 端点使用 query param：
```bash
curl "http://localhost:8000/mcp?key=YOUR_API_KEY"
```

## 7. 错误处理

| 场景 | HTTP Status | 错误信息 |
|------|-------------|----------|
| 缺少 API Key | 401 | `Missing API key. Provide via ?key= query param` |
| 无效 API Key | 401 | `Invalid API key` |
| 非管理员操作 | 403 | `Admin privileges required` |
| 资源不存在 | 404 | `User/Skill not found` |
| 参数错误 | 422 | Pydantic validation error |
