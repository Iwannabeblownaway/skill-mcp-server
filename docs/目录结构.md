## 目录说明

### `app/` - 主应用目录

| 目录/文件 | 说明 |
|-----------|------|
| `main.py` | FastAPI 应用入口，挂载 MCP 和 REST API |
| `api/` | REST 管理接口 |
| `mcp/` | MCP 协议实现（server.py） |
| `services/` | 业务逻辑层 |
| `db/` | 数据库连接和 CRUD |
| `models/` | Pydantic 数据模型 |

### `tests/` - 测试目录

| 文件 | 说明 |
|------|------|
| `conftest.py` | pytest fixtures，mock 数据 |
| `test_api/` | API 端点测试 |
| `test_services/` | Service 层测试 |

### `scripts/` - 辅助脚本

| 文件 | 说明 |
|------|------|
| `init_db.sql` | MySQL 建表语句 |
| `seed_data.py` | 创建 admin 用户和示例 skills |

### `docs/` - 文档目录

| 文件 | 说明 |
|------|------|
| `README.md` | 项目说明（同根目录） |
| `需求文档.md` | 功能需求清单 |
| `架构文档.md` | 技术架构设计 |
| `OpenCode测试指南.md` | OpenCode MCP 配置指南 |

## 关键文件

| 文件 | 行数 | 主要功能 |
|------|------|----------|
| `app/mcp/server.py` | 284 | MCP Server + Auth Middleware + Permission Filter |
| `app/services/skill_service.py` | 92 | 技能获取、权限检查、日志记录 |
| `app/api/v1/users.py` | 56 | 用户创建（返回 API Key） |
| `tests/conftest.py` | 342 | 测试 fixtures 和 mocks |
