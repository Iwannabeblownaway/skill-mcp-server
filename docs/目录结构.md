## 目录说明

### `app/` - 主应用目录

| 目录/文件 | 说明 |
|-----------|------|
| `main.py` | FastAPI 应用入口，挂载 MCP 和 REST API |
| `config.py` | 配置管理，从 .env 读取 |
| `api/` | REST 管理接口 |
| `mcp/` | MCP 协议实现 |
| `services/` | 业务逻辑层 |
| `db/` | 数据库连接和 CRUD |
| `models/` | Pydantic 数据模型 |
| `core/` | 核心功能（security, exceptions） |
| `utils/` | 工具（logger, redis） |

### `tests/` - 测试目录

| 文件 | 说明 |
|------|------|
| `conftest.py` | pytest fixtures，mock 数据 |
| `test_api/` | API 端点测试 |
| `test_services/` | Service 层测试 |

### `scripts/` - 辅助脚本

| 文件 | 说明 |
|------|------|
| `seed_data.py` | 创建 admin 用户和示例 skills |
| `init_db.sql` | MySQL 建表语句 |
| `register_new_skills.py` | 注册技能到数据库 |
| `migrate_add_content_json.sql` | 数据库迁移脚本 |

### `docs/` - 文档目录

| 文件 | 说明 |
|------|------|
| `需求文档.md` | 功能需求清单 |
| `架构文档.md` | 技术架构设计 |
| `目录结构.md` | 本文件 |
| `OpenCode测试指南.md` | OpenCode MCP 配置指南 |
| `prompt.md` | 开发提示词 |

## 关键文件

| 文件 | 主要功能 |
|------|----------|
| `app/mcp/server.py` | MCP Server + Auth Middleware |
| `app/mcp/handlers.py` | MCP 工具处理 (list_tools, call_tool) |
| `app/services/skill_service.py` | 技能获取、权限检查、日志记录 |
| `app/api/v1/skills.py` | 技能 CRUD 和文件管理 |
| `app/api/v1/users.py` | 用户管理 |
