# 需求文档：SKILL 服务端（MCP 协议）

> 版本：v1.2 | 更新日期：2026-04-17

## 1. 项目背景

需要一个中心化的服务端，用于管理团队内部的 SKILL（技能定义），并通过 MCP 协议对外提供服务。本地 AI Agent（如 Claude Code、OpenCode）作为 MCP 客户端，可以连接该服务端，动态获取当前用户被授权的 SKILL 列表，并调用 SKILL 内容。

服务端需要提供用户认证、技能管理、权限控制和调用审计功能。

## 2. 核心需求

### 2.1 用户管理 ✅ 已实现

支持创建、查询用户。

每个用户拥有：
- `external_id` - 外部系统唯一标识（VARCHAR, UNIQUE）
- `username` - 显示名称
- `api_key` - API Key（用于 MCP 客户端认证，VARCHAR, UNIQUE, 32位）
- `role` - 角色（`admin` 或 `user`）
- `created_at` - 创建时间

### 2.2 技能管理 ✅ 已实现

支持创建、更新、删除技能。

每个技能包含：
- `name` - 名称（唯一标识）
- `description` - 描述（用于 AI 隐式触发）
- `path` - 相对路径（指向 skills/ 下的目录）
- `version` - 版本号（默认 1.0）
- `created_at` / `updated_at` - 时间戳
- `content_json` - 可选的 JSON 格式内容缓存

### 2.3 权限管理 ✅ 已实现

- 管理员可以为用户授权技能（多对多，user_skills 表）
- 用户在请求技能列表时，服务端只返回已授权的技能
- 权限变更实时生效（无需重启客户端）

### 2.4 MCP 服务接口 ✅ 已实现

服务端暴露 MCP 协议接口（Streamable HTTP transport）：

| 方法 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `initialize` | 协议初始化 | protocolVersion, capabilities | serverInfo |
| `tools/list` | 返回用户授权的 Skills | 无 | Skill 列表 |
| `tools/call` | 获取 Skill 内容 | skill_name | Skill 内容 |
| `get_skill_index` | 获取文件索引 | skill_name | 文件列表 |
| `get_skill_file` | 读取单个文件 | skill_name, file_path | 文件内容 |

### 2.5 调用审计 ✅ 已实现

记录每次 skill 调用：

| 字段 | 说明 |
|------|------|
| `user_id` | 用户 ID |
| `skill_id` | 技能 ID |
| `call_time` | 调用时间 |
| `status` | 状态（success/failure/denied） |
| `error_message` | 错误信息（如有） |
| `duration_ms` | 耗时（毫秒） |

### 2.6 认证与安全 ✅ 已实现

- MCP 客户端连接时提供 API Key（通过 `X-API-Key` header 或 `?key=` query param）
- 服务端验证 API Key 并关联到对应用户
- 使用 SQL 参数化查询防止注入
- 文件操作有路径穿越防护

## 5. 数据库设计

### users 表
```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id VARCHAR(100) UNIQUE NOT NULL,
    username VARCHAR(100) NOT NULL,
    api_key VARCHAR(64) UNIQUE NOT NULL,
    role ENUM('admin', 'user') DEFAULT 'user',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_api_key (api_key),
    INDEX idx_user_id (user_id)
);
```

### skills 表
```sql
CREATE TABLE skills (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) UNIQUE NOT NULL,
    description TEXT NOT NULL,
    path VARCHAR(500) NOT NULL,
    version VARCHAR(20) DEFAULT '1.0',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    content_json TEXT,
    INDEX idx_name (name)
);
```

### user_skills 表
```sql
CREATE TABLE user_skills (
    user_id INT NOT NULL,
    skill_id INT NOT NULL,
    granted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (user_id, skill_id),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (skill_id) REFERENCES skills(id) ON DELETE CASCADE
);
```

### skill_calls 表
```sql
CREATE TABLE skill_calls (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    skill_id INT NOT NULL,
    call_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status ENUM('success', 'failure', 'denied') NOT NULL,
    error_message TEXT,
    duration_ms INT,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (skill_id) REFERENCES skills(id),
    INDEX idx_user_time (user_id, call_time),
    INDEX idx_skill (skill_id)
);
```

## 6. 典型使用流程

1. **管理员** 创建技能 `code-review`，授权给用户 Alice
2. **Alice** 在 OpenCode 配置 MCP 客户端，设置服务端地址和她的 API Key
3. **OpenCode** 连接服务端，调用 `tools/list`，获得 Alice 授权的技能列表
4. **OpenCode** 根据任务自动决定调用 `tools/call`，传入 `skill_name="code-review"`
5. **服务端** 验证 Alice 权限，记录调用日志，返回技能内容
6. **OpenCode** 根据返回的技能内容执行审查
