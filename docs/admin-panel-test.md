# Skill MCP Server 管理界面测试指南

## 测试前准备

### 1. 启动服务
```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 2. 访问管理界面
浏览器打开：**http://localhost:8000/admin**

---

## 一、仪表盘

访问 `/admin` 查看概览。

**验证项：**
- [ ] 显示用户总数
- [ ] 显示技能总数
- [ ] 显示授权总数
- [ ] 快捷操作链接正常

---

## 二、用户管理

### 2.1 创建用户

1. 点击 **+ 创建用户**
2. 填写表单：
   - **User ID**：`bob`（可选，不填则自动生成）
   - **用户名**：`Bob`
   - **角色**：`user`
3. 点击 **创建用户**

**验证：**
- [ ] 显示成功消息和 API Key
- [ ] API Key 仅显示一次，请妥善保存

### 2.2 查看用户列表

访问 `/admin/users`

**验证：**
- [ ] 显示所有用户
- [ ] 角色有颜色标签

### 2.3 查看用户详情

点击用户名进入详情页

**验证（普通用户）：**
- [ ] 显示 User ID、用户名、角色
- [ ] 显示 API Key（含重置功能）
- [ ] 显示已授权技能
- [ ] 可以授予/撤销技能

**验证（Admin 用户）：**
- [ ] 自动拥有所有技能（无需手动授权）
- [ ] 没有"授予新技能"区域

### 2.4 重置 API Key

点击 **重置 Key**

**验证：**
- [ ] 生成新 Key
- [ ] 新 Key 仅显示一次

### 2.5 更新用户信息

在用户详情页可以更新用户名、User ID、角色

**验证：**
- [ ] 更新成功

### 2.6 删除用户

点击 **删除用户**

**验证：**
- [ ] 用户从列表消失
- [ ] 关联的授权记录同时删除

---

## 三、技能管理

### 3.1 创建技能

1. 点击 **+ 创建技能**
2. 填写：
   - **技能名称**：`test-skill`
   - **描述**：`测试用技能`
   - **依赖**：`sorftime,aws`（可选，MCP 服务依赖）
3. 点击 **创建**

**注意：**
- 新创建的技能状态为 **draft**（草稿），需要上传文件后才能激活
- 只有 **active** 状态的技能才能授权给用户

**验证：**
- [ ] 跳转到详情页
- [ ] 技能状态为 draft

### 3.2 上传文件

在技能详情页上传文件或压缩包

**验证：**
- [ ] 文件保存成功
- [ ] 上传后自动生成 .skill 安装包
- [ ] 技能状态变为 **active**

### 3.3 下载技能包

点击 **下载技能包** 按钮

**验证：**
- [ ] 下载为 .zip 文件（可直接解压使用）

### 3.4 更新技能信息

在技能详情页可以更新描述和依赖

**验证：**
- [ ] 更新成功

### 3.5 重建技能包

点击 **重建安装包**

**验证：**
- [ ] 重新生成 .skill 包

### 3.6 查看技能列表

访问 `/admin/skills`

**验证：**
- [ ] 显示所有技能
- [ ] 显示状态标签（draft/active）
- [ ] 显示已授权用户数

### 3.7 删除技能

点击 **删除技能**

**验证：**
- [ ] 技能消失
- [ ] 同时删除 .skill 安装包

---

## 四、授权管理

### 4.1 授予技能

1. 进入普通用户详情
2. 选择技能，点击 **授予**

**注意：**
- 只能授权 **active** 状态的技能
- draft 状态的技能无法授权

**验证：**
- [ ] 技能出现在列表

### 4.2 撤销技能

点击技能旁边的 **撤销**

**验证：**
- [ ] 技能消失

### 4.3 集中管理

访问 `/admin/authorizations`

**验证：**
- [ ] 显示所有授权关系
- [ ] 可批量授予/撤销

---

## 注意事项

1. **API Key**：创建后立即复制，无法再查看（可重置）
2. **Admin**：自动拥有所有技能，不在 `user_skills` 表存储
3. **技能状态**：
   - **draft**：草稿状态，未上传文件，无法授权
   - **active**：已激活，可授权给用户
4. **MCP 依赖**：技能可声明所需的外部 MCP 服务，调用时会自动提示配置指南
