# Data Analysis Skill

Analyze datasets and generate summary statistics and visualizations.

## 1. Data Loading
- Load data from CSV, Excel, JSON, or database
- Handle encoding issues
- Detect delimiter and header row

## 2. Data Profiling
- Row/column counts
- Data types detection
- Missing values analysis
- Unique value counts
- Statistical summary (mean, median, std, etc.)

## 3. Data Cleaning
- Handle missing values (drop, fill, interpolate)
- Remove duplicates
- Fix encoding issues
- Validate data types

## 4. Visualization
- Distribution plots (histogram, box plot)
- Correlation heatmaps
- Time series plots
- Category breakdowns

## 5. Analysis Types

### Descriptive Statistics
```
- Count, mean, median, mode
- Standard deviation, variance
- Min, max, quartiles
- Skewness, kurtosis
```

### Trend Analysis
```
- Moving averages
- Growth rates
- Seasonality detection
```

### Group Comparisons
```
- GroupBy aggregations
- Cross-tabulations
- Statistical tests (t-test, chi-square)
```

## Output Format

Provide analysis in markdown with:
1. Executive summary
2. Key findings
3. Supporting visualizations (ASCII/URL)
4. Recommendations
